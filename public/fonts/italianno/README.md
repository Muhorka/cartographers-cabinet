# Italianno

The `Italianno-Regular.ttf` file is an unmodified official Google Fonts web
asset, loaded locally for the Cabinet masthead. It is served by the CSS API at
the following URL (font family `Italianno`, revision `v18`):

https://fonts.gstatic.com/s/italianno/v18/dg4n_p3sv6gCJkwzT6Rnjw.ttf
