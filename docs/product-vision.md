# Product vision

## Purpose

Create a visual spatial-worldbuilding workshop in which people and browser agents jointly design, inspect, validate, and revise fictional places. The application should understand not only geometry, but also hierarchy, explicit passages, routes, roles, access, constraints, provenance, and narrative intent.

The WebMCP Challenge is the first delivery milestone and a source of momentum. The product is primarily intended to become a useful long-term tool for complex fictional settings.

## Core promise

Describe or draw a place, express how it should function, and let the application and agent show whether the resulting space actually supports the intended story.

## Product character

The initial interface is a historical cartographer's workshop: handmade paper, graphite, brass, dark green cloth, muted correction red, evening warmth, pencil irregularity, and steel-nib annotations. It should feel like a working atlas and drawing table rather than a contemporary vector editor wearing a decorative theme.

The underlying geometry remains exact. Visual imperfection belongs to rendering, never to measurements, hit targets, validation, or stored coordinates.

## Generality

The hackathon demonstration may use a synthetic historical estate, manor, farm, or village. The engine must remain genre-independent. Project owners define their own entity types, roles, groups, properties, constraints, movement profiles, and later scenarios. The same mechanisms must support a palace ball, a village attacked by drowners, and a spacecraft emergency.

## Human-agent collaboration

The human edits directly and judges spatial quality. The application owns deterministic geometry and validation. The agent interprets intent, inspects structured state, creates proposals, requests visual explanations, and revises its work. Significant changes appear on a correction-tracing overlay and require review before becoming a checkpoint.

## Privacy

The public project contains only synthetic fixtures. Private source files and data remain outside this repository and outside every deployment.
